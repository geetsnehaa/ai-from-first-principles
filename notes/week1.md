## Git vs GitHub
Git is a tool for version control. From the reading, there are different kinds of
version control: local, central, and distributed. Git is distributed, which means
every clone carries the full history, not just the latest copy.

GitHub is the cloud service that hosts Git repositories so I can back them up,
share them, and show them as a portfolio. Git is the tool, GitHub is the place.

## What I did

- Watched my file travel from my laptop up to GitHub

## Commit vs push (the thing I want to remember)
- commit saves a snapshot to my LOCAL history. Nothing leaves my machine.
- push uploads those local commits to GitHub, over the internet.
- Order is always commit first, then push.
- Commit saves. Push publishes.
