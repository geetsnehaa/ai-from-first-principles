# AI From First Principles

A 6-week sprint to learn how AI actually works, built in public.

I'm treating myself as the case study: run a hard thing, build the method that does
it again, and share the whole messy middle along the way. The topic is AI. The real
output is a repeatable way to learn anything.

## What I'm building

- A tiny GPT, trained from scratch, to understand language models from the ground up
- Jarvis, my own tool-using agent
- A product teardown, done carefully
- A running set of notes and posts as I go

## The sprint

- [ ] Week 1, Foundations: how LLMs work, in my own words
- [ ] Week 2, Build begins: a transformer block, by hand
- [ ] Week 3, Shipping: first trained model, plus a data cert
- [ ] Week 4, Jarvis: my own agent
- [ ] Week 5, Capstone: portfolio and teardown
- [ ] Week 6, Conversion: turning it all into what comes next

I'll check these off as I ship, and link each one here.

## Why first principles

Because understanding beats memorizing. I'd rather build the small version by hand
and know why it works than wire together things I can't explain. One source per
topic, everything else optional, and no rabbit holes.
